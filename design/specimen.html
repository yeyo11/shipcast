    Colour

    One yellow does all the brand work. Black carries structure. Red is only for failure.

    Type

    Phudu, heavy and uppercase, for display only (24 px and up). Inter Tight for everything people read. JetBrains Mono only for commands, versions and launch.yml.

    Rules

    Do

    • One yellow primary action per view, with its stamp shadow.
    • Display type uppercase, heavy, tight; everything else sentence case.
    • Alternate bands: neutral, yellow, black. Close with black.
    • Hard 2–2.5 px outlines and offset stamp shadows for depth.
    • Every state as a word and a shape.

    Don't

    • No soft or blurred shadows, no gradients, no glow.
    • No yellow text on light grounds; yellow is a fill there.
    • No Phudu below 24 px or for running text.
    • No colour that is not in the palette; red only for failure.
    • No rockets, no navy, no cyan: those belong to other brands.
